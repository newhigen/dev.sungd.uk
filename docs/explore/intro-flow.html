소개 탭 흐름 — 판 일곱

반반 판 아래를 어떻게 이어갈지. 약수첩 소개 탭을 판마다 실제로 빌드해 놓았다 — 축소해서 보이는 것일 뿐 실물이다.

지금 걸리는 것 셋: 다음 탭 카드가 맨 위라 다 읽기 전에 나가고, 기능 절이 글과 큰 폰 그림으로 늘어지고, 그 그림이 아래 「화면」 절과 겹친다.

A 지금

판 → 캡션 → 다음 탭 → 하루 타임라인 → 주요 기능(큰 그림 둘) → 화면 → 설치.

A 에서 다음 탭 카드만 맨 아래로 내린다. 끝까지 읽고 나가게. 나머지는 그대로.

C 기능을 화면에 붙임

「주요 기능」 네 꼭지를 없애고 화면 넷에 설명을 붙인다. 큰 폰 그림 둘이 빠져 페이지가 확 짧아진다.

E 화면만

글을 다 걷는다. 「하루 타임라인」는 왜 탭에 이미 있으니 소개에서 빼고, 판 → 화면 넷 → 설치만 남긴다. 가장 짧다.

크게 보기 →

F 화면이 말하게

기능 설명을 본문에서 빼 화면 위 번호로 옮긴다. 읽는 대신 보게 — 원티드 출품작 판에서 뽑은 기법이다.

크게 보기 →

G E + F

뼈대는 E 로 줄이고, 기능 설명은 F 의 번호로. 번호가 쓴 화면은 아래 목록에서 빼 같은 화면이 두 번 안 나온다.

크게 보기 →
A → E 로 갈수록 글이 준다. B·C·D 는 서로 독립이라 「B + C」 처럼 섞어도 되고, E·F 는 C 를 더 민 쪽이다.
  • B 는 순서만 바꾼다 — 열두 편에 기계로 적용된다.
  • C 는 기능 글을 화면 캡션으로 옮긴다. 편마다 문장을 새로 써야 한다.
  • D 는 「하루 타임라인」 절이 있는 편에만 걸린다 — 열둘 중 셋(약수첩·준비물·쿠폰함).
  • E 는 하루 절까지 뺀다. 같은 도식을 두 판에 싣지 않는다는 규칙과 맞는다.
  • F 는 화면마다 번호 넷을 새로 찍어야 한다 — 손이 제일 많이 간다. 캡처가 없는 편(CLI·확장)엔 못 쓴다.
  • G 는 둘을 합친 것 — 화면이 있는 편은 이쪽, 없는 편(워밍업·세션 탭)은 E 로 간다.
