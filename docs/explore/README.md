# 시안 페이지

갈림길마다 안을 실제 크기로 그려 놓고 고른 화면들. 고르고 나면 그 판이 왜 그렇게 생겼는지가
여기 남는다.

| 파일 | 무엇을 골랐나 |
|---|---|
| `tabs.html` | 소개·개발기를 잇는 방법 일곱. 밑줄 탭이 안 보이던 문제 |
| `tabs2.html` | 탭이 셋·넷이 되면 — 세그먼트는 넷부터 무너진다 |
| `tabs3.html` | 떠 있는 띠의 재질 여섯. 애플이 쓰는 유리(흐림 + 채도 + 흰 테 + 그림자) |
| `tabs4.html` | 칩 색 여덟. 흰 칩이 흰 종이 위에서 사라지던 문제 — 바닥을 짙게 하는 쪽으로 |
| `why-numbers.html` | 왜 만들었나에 숫자를 넣는 판 다섯 — Claude 워밍업으로. 숫자 셋 · 하루 도식 · 막대 · 카드 · 타일 |
| `warmup-visual.html` | 소개·개발기의 줄글 여섯 자리를 도식으로 — 지금과 시안을 나란히 |
| `tone.html` | 말투 다섯 — 평서체 · 해요체 · 합니다체 · 개조식 · 섞기. 같은 판을 다섯 번 |
| `warmup-promo.html` | 홍보 관점 여섯 — 소개 첫 화면(은퇴 띠 · 숫자 훅 · 도식 중복 걷기) · 아래 절반 · 개발기 첫 화면 · 공유 표지 |
| `warmup-retire.html` | 종료 표시 셋 — 제목 옆 칩 · 본문 첫 줄 상태 두 칸 · 대표 숫자 아래 «지금» 칸. 훅 표기 셋 |
| `status-badge.html` | 상태 배지 — 용어 넷(폐기 · 종료 · 보관 · 대체됨) × 모양 넷(점 · 옅은 바탕 · 테두리 · 채움), 글머리와 목록 카드에 놓은 판 |
| `home.html` | 홈 화면 다섯 — 지금 · A 폭 채운 3열 · B 사용 중 카드 + 나머지 목록 · C 왼쪽 난 거르기 · D 대장 한 줄 목록 · E 대표 셋 크게 |

로컬에서 보려면 `npx http-server docs/explore -p 4398 -s -c-1`.
