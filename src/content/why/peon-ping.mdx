세션 모니터(claude-watch) 화면에는 세션마다 완료인지 입력을 기다리는지가 떴다. 그 화면을 보고 있을
때는 충분했다. 다른 창에서 일하는 동안에는 세션이 끝나도 알 방법이 없었다.

터미널에도 완료 알림이 있었지만 소리가 나지 않았다.

## 그래서 정한 것

**터미널을 거치지 않는다.** 벨과 tmux 를 우회해 Claude Code 훅에서 직접 소리를 낸다.

**사람 목소리, 세 문장.** 완료 · 입력 필요 · 한도만. 무슨 일인지 문장으로 들린다.

**가볍게.** 소리 때문에 세션이 무거워지지 않는다. 훅은 컨텍스트에 들어가지 않는다.
