## 그래서 정한 것

**터미널을 거치지 않음.** 벨과 tmux 를 우회해 Claude Code 훅에서 직접 재생.

**사람 목소리, 세 문장.** 완료 · 입력 필요 · 한도만. 무슨 일인지 문장으로 전달.

**가볍게.** 훅은 컨텍스트 밖이라 세션 부담 없음.
