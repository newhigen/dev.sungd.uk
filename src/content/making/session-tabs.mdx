## 옆으로 자란 것

9월 5일 오후 PR #29 부터 같은 데몬 위에 세션 판(Deck) · 메뉴바 SessionBar · 알림을 얹음. PR 80개 중 절반 넘게가 그쪽 — 탭 정리가 아니라 «어느 세션에 손댈지» 의 이야기라 이 편에서 뺌.

## 배운 점

**전환 경로에는 순수 UI 만.** 탭 이동 · 창 전환은 렌더러와 창 관리자를 부름. 접기 · 펴기는 그룹 속성 하나.

**공유 서버에서 포트는 주인을 못 정함.** 주소에서 가장 구체적인 조각(경로)부터 봄.
