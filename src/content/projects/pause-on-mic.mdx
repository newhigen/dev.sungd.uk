## 동작 방식

앱을 지켜보지 않고 **마이크 자체**를 본다. 맥이 녹음을 시작했는지 CoreAudio 에 직접 묻는다 —
`kAudioDevicePropertyDeviceIsRunningSomewhere`. 이름이 비슷한 `goin` 은 내 프로세스 기준이라
남이 녹음해도 계속 꺼짐으로 나온다.

`config.json` 의 `player` 로 고른다. adb 갈래를 먼저 만들었다 — 문서가 SDK 와 API 를 섞어 말해
Premium Basic 에서 재생 조종이 되는지 확언이 안 됐다. 붙여 보니 멈춤과 재생 둘 다 먹어서
Spotify 를 기본으로 두고 adb 는 무선 디버깅이 꺼져 있을 때의 대비로 남겼다.

## 설치와 요구 사항

macOS 와 Python 3. `./install.sh` 를 돌리면 launchd 에 올라가 로그인 때 저절로 뜬다.
Spotify 갈래를 쓰려면 개발자 대시보드에서 앱을 만들고 `python3 spotify_auth.py` 로 토큰을
한 번 받는다. 토큰은 키체인에 들어간다.

지금 마이크가 켜져 있는지는 `python3 micstate.py`, 무엇이 일어났는지는
`~/Library/Logs/pause-on-mic.log` 에서 본다.

만들면서 밟은 함정 — 이름이 비슷한 CoreAudio 상수, 본문 없이 오는 204, PATH 가 빈 launchd —
은 저장소의 `HISTORY.md` 에 적어 뒀다.
