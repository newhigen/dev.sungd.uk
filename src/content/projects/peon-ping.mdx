Claude Code 세션을 여러 개 띄워 두고 일하면, 어느 세션이 끝났는지는 그 창을 봐야 안다.
터미널(Ghostty)의 완료 알림은 소리가 꺼진 채였고, 세션을 모아 둔 tmux 화면 안에서는
알림 자체가 오지 않았다.

그래서 세션의 상태를 목소리로 듣게 했다. 오픈소스 알림 훅 peon-ping 을 깔고, 거기에
ElevenLabs 로 만든 목소리 팩을 얹었다. 세션이 끝났을 때 · 나를 기다릴 때 · 한도에 닿았을 때,
세 경우에만 울린다. 열흘 쓰고 지웠다.

## 주요 기능

### 소리 분류 셋

peon-ping 은 세션 시작 · 작업 접수 · 완료 · 오류 · 입력 필요 · 한도 · 연타, 일곱 경우를 가른다.
완료 · 입력 필요 · 한도 셋만 켰다. 오류도 대개 완료나 입력 필요로 도착하고, 계획 검토는 입력
필요와 성격이 같다.

### 직접 만든 목소리 팩

게임 효과음이 기본인 팩 대신 사람 목소리로 만들었다. ElevenLabs 의 Matilda 목소리를 v3 모델에
넣고 문장 앞에 `[excited]` 지시를 붙였다. 팩 포맷은 `openpeon.json` 과 `sounds/<분류>_NN.mp3` 가
전부라, 분류 이름대로 파일을 놓으면 새 소리가 된다.

### 세 기계에 같은 소리

Claude Code 를 쓰는 세 기계가 같은 목소리를 내도록 팩과 설정을 설정 repo(claude-config)에 두었다.
peon-ping 이 관리하는 폴더에 두면 업데이트나 팩 정리 명령에 지워지기 때문이다. 설정은 통째로
덮지 않고 다섯 키만 넣는다.

### 헤드폰일 때만

사무실 스피커로 소리가 나지 않게, 블루투스나 USB 헤드폰이 연결돼 있을 때만 소리를 통과시키는
스크립트를 앞에 세웠다.
