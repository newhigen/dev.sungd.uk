## 주요 기능

### 출근 시각 하나로 계산

<Chain steps={[
  { op: "입력", v: "07:00", name: "출근", key: true },
  { op: "−3:01", v: "03:59", name: "첫 메시지" },
  { op: "+5:01", v: "09:00", name: "두 번째 · 출근 +2시간 정각" },
  { op: "+10:02", v: "14:01", name: "세 번째" },
]} />

1분씩 둔 여유로 시각 오차 흡수. 설치 전 윈도우별 근무 중 사용 시간 표로 확인.

### 한 메시지짜리 호출

`claude -p "ok" --model haiku --no-session-persistence` 한 줄. 가장 작은 모델 · 짧은 응답 · 세션 미저장으로
호출 자체의 사용량은 무시 수준. 목적은 윈도우 개방.

### 새벽에 맥 깨우기

`pmset` 으로 첫 메시지 5분 전 맥 기상, `launchd` 가 정한 시각에 실행. 호출은 `caffeinate -i` 로 감싸 실행 도중
절전 방지.
