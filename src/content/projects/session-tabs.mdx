- **접기 · 펴기뿐** — 탭을 옮기지 않아 페이지가 다시 안 그려지고 스크롤 위치도 그대로.
- **창은 하나** — 세션마다 창을 띄우지 않음. 보조 모니터에 띄운 창의 탭은 안 건드림.

## 설치와 요구 사항

- **크롬** — 116 이상. `extension/` 을 압축해제된 확장 프로그램으로 로드.
- **Mac** — 데몬(포트 8908)을 launchd 로 상주. Claude Code `settings.json` 에 SessionStart · SessionEnd 훅 두 개.
- 저장소는 private.
