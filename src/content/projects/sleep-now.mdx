## 핵심 기능

### 알림이 본체

수면 앱 대부분은 사후 분석(어젯밤 수면 시간 · 깊은 잠 비율). 판단 시점은 눕기 전이고, 필요한 값은
**지금 누우면 몇 시 기상** 하나. One UI 8 Now Bar 에 올려 잠금화면 하단에 상시 표시.

<Fig src="/p/sleep-now/nowbar.png"
  caption="잠금화면 Now Bar. 화면을 켜지 않아도 남은 시간 표시." />

### 하룻밤 타임라인

현재 · 목표 취침 · 지금 자면 기상 · 목표대로면 기상 · 회사 도착을 한 축에, 항목 사이 간격은 분 단위로.

<Fig src="/p/sleep-now/app-light.png" srcDark="/p/sleep-now/app-dark.png" phone
  caption="왼쪽 괄호가 같은 수면 시간(7시간 15분)을 두 번 잼. 위가 목표, 아래가 지금 누웠을 때 — 늦은 만큼 아침 전체가 밀림." />

### 위젯

같은 값을 한 줄로 + 버튼 둘. 두 칸까지 좁힘 가능, 낮에는 버튼 숨김.
